## Silent Installation

```cmd
:: Minimal (CP + Tray only)
Setup_WireGuardCredentialProvider_x64.exe /S

:: With registry parameters (all optional, combinable)
Setup_WireGuardCredentialProvider_x64.exe /S /SMARTCARD=1 /THUMBPRINT=164F6689... /DISCONNECTREMOVE=1
Setup_WireGuardCredentialProvider_x64.exe /S /LOGLEVEL=3
Setup_WireGuardCredentialProvider_x64.exe /S /HANDSHAKE=180 /TILELABEL="Corporate VPN"
Setup_WireGuardCredentialProvider_x64.exe /S /CONFIGDIR="C:\WG\Configs\"

:: Full install (CP + Tray + all YubiKey tools)
Setup_WireGuardCredentialProvider_x64.exe /S /FULL

:: Individual YubiKey components
Setup_WireGuardCredentialProvider_x64.exe /S /YKAUTH /YKMINI /YKMGRCLI

:: Silent uninstall
Uninstall.exe /S
```

## Silent Parameters

| Parameter | Type | Description | Example |
|---|---|---|---|
| `/LOGLEVEL=n` | REG_SZ | Log level (0=off, 1=crit, 2=warn, 3=debug) | `/LOGLEVEL=3` |
| `/HANDSHAKE=n` | REG_SZ | Handshake timeout in seconds (0=disabled) | `/HANDSHAKE=180` |
| `/THUMBPRINT=hex` | REG_SZ | YubiKey certificate SHA-1 thumbprint (40 hex chars) | `/THUMBPRINT=164F...` |
| `/SMARTCARD=1` | REG_DWORD | Enable SmartcardEnabled | `/SMARTCARD=1` |
| `/PINREQUIRED=1` | REG_DWORD | Enable PIN prompt | `/PINREQUIRED=1` |
| `/DISCONNECTREMOVE=1` | REG_DWORD | Disconnect tunnel when YubiKey is removed | `/DISCONNECTREMOVE=1` |
| `/TILELABEL=text` | REG_SZ | Label for the pre-logon credential tile | `/TILELABEL="Corporate VPN"` |
| `/CONFIGDIR=path` | REG_SZ | WireGuard configuration directory | `/CONFIGDIR="C:\WG\"` |
| `/UPDATECHECK=n` | REG_DWORD | Enable/disable update check (1/0) | `/UPDATECHECK=0` |
| `/UPDATECHECKVISIBLE=n` | REG_DWORD | Show/hide update-check UI in tray menu and About (1/0) | `/UPDATECHECKVISIBLE=0` |
| `/UPDATECHECKINTERVAL=n` | REG_DWORD | Minutes before first update check after startup | `/UPDATECHECKINTERVAL=10` |

> Parameters are always applied — including during updates. Parameters not specified remain unchanged.

## Checksums

After each build, `build.bat` generates a `checksums.txt` in `sha256sum` format:

```
<sha256-hash>  Setup_WireGuardCredentialProvider_x64.exe
```

The file is ready to upload alongside the installer on GitHub Releases. Verification on Windows:

```powershell
(Get-FileHash .\Setup_WireGuardCredentialProvider_x64.exe -Algorithm SHA256).Hash.ToLower()
# Compare with the hash in checksums.txt
```

## Update Behavior

The installer is update-safe:

- **Processes**: `WireGuardCPTray.exe` and `WireGuardShutdownService.exe` are terminated via
  the `nsProcess` plugin. The installer actively polls until the processes are gone
  (250 ms interval, 10 s timeout) before copying new binaries — no "file in use" dialog.
- **LogonUI.exe**: not killed (protected system process running as SYSTEM/PPL —
  `taskkill /F` would hang indefinitely). LogonUI automatically reloads the new DLL on the
  next Winlogon cycle (screen lock or next login).
- **Registry**: User settings (SmartcardEnabled, Thumbprint, etc.) are not overwritten
  during updates. `HandshakeTimeoutSec` is set to `180` if the value is `0` or empty.
- **Silent parameters** (`/HANDSHAKE=`, `/LOGLEVEL=`, etc.) always overwrite — including
  during updates.

## YubiKey PIV Setup (`Setup-YubiKey.ps1`)

The PowerShell script configures a YubiKey 5 Series for smartcard authentication.

**Prerequisites:**
- YubiKey Manager CLI (`ykman`) installed and in PATH
- PowerShell running as Administrator
- YubiKey 5 Series inserted
- YubiKey Minidriver installed (for PIV driver support)

**Run:**
```powershell
Set-ExecutionPolicy Bypass -Scope Process
.\Setup-YubiKey.ps1
```

**Menu:**

| Option | Description |
|---|---|
| **1 – Initialize YubiKey** | Full PIV reset, generate key + certificate, write to registry |
| **2 – Register existing YubiKey** | Read thumbprint from inserted YubiKey, write to registry |
| **3 – Export setup report** | Re-create report from inserted YubiKey |

**What the script does (Option 1):**
1. Check prerequisites (`ykman` present, Administrator rights, PIV enabled)
2. Reset the PIV application
3. Generate a random 8-digit PIN and PUK
4. Query the username (AD lookup or manual entry)
5. Generate an RSA2048 key pair in slot 9a
6. Issue a self-signed certificate (10-year validity)
7. Write `SmartcardEnabled=1` and `SmartcardCertThumbprint` to registry
8. Set `SmartcardDisconnectOnRemove=1`
9. Save a setup report with PIN/PUK to the chosen location

**Error handling (since 2026.8.4):**
- No abrupt exit on errors — the script returns to the main menu after failures
- All `ykman` calls go through `Invoke-Ykman` with clear error output including ykman's own message
- Recognized error conditions with actionable hints:
  - `ykman` not found → download link
  - No YubiKey detected → USB hint, driver link
  - PIV not available → model hint
  - PIV disabled → `ykman config usb --enable PIV`
  - Slot 9a empty → refer to Option 1
  - Missing Minidriver → Yubico Smart Card Drivers download link

> **Supported YubiKey models:** 5 NFC, 5C, 5Ci, 5 Nano, 5C NFC, 5C Nano
> **Not supported:** YubiKey Bio, Security Key series, YubiKey 4 Series

## Registry Keys

`HKLM\SOFTWARE\Jens Kaesler\WireGuard Credential Provider`

The installer sets the following values:

| Value | Type | Description |
|---|---|---|
| `ExePath` | REG_SZ | Path to `wireguard.exe` |
| `WgExePath` | REG_SZ | Path to `wg.exe` |
| `ConfigDir` | REG_SZ | Configuration directory |
| `InstallDir` | REG_SZ | Installation directory |
| `LogLevel` | REG_SZ | Log level as decimal string (`"1"`=CRIT, `"3"`=DEBUG) |
| `LogRetentionDays` | REG_SZ | Delete log files older than N days (`"7"`) |
| `HandshakeTimeoutSec` | REG_SZ | Disconnect tunnel if handshake is older than N seconds (`"180"`) |
| `AutoUpdateCheck` | REG_DWORD | Check GitHub for new releases on startup (`1`=on, `0`=off, default: `1`) |
| `AutoUpdateCheckVisible` | REG_DWORD | Show update-check UI in tray menu and About dialog (`1`=show, `0`=hide, default: `1`) |
| `AutoUpdateCheckInterval` | REG_DWORD | Minutes to wait before the first update check after startup (default: `5`) |

`SmartcardEnabled` and `SmartcardCertThumbprint` are set by `Setup-YubiKey.ps1`.

> **Note:** `LogLevel`, `LogRetentionDays` and `HandshakeTimeoutSec` are stored as `REG_SZ`.
> Enter the decimal number as plain text in Registry Editor — no hex conversion needed.

## Autostart

The tray app starts automatically via a shortcut in `CommonStartup` with the
`RunAsAdministrator` flag set. This ensures the app runs as Administrator without a UAC
prompt (even when UAC is disabled).

The shortcut is removed automatically on uninstall.

## Corporate Network Detection

The tray app automatically detects whether the machine is on the corporate network and
disconnects the VPN tunnel:

**Stage 1** – Windows NLA: `INetworkListManager` reports a `DOMAIN_AUTHENTICATED` network.

**Stage 2** – Fallback for VMs (Red Hat VirtIO, Hyper-V) where NLA only reports `PRIVATE`:
1. Registry check: machine is domain-joined (`SYSTEM\...\Tcpip\Parameters\Domain`)
2. At least one non-WireGuard LAN adapter with an active IPv4 address is present
3. `DsGetDcName` finds a domain controller on the network
4. `GetBestRoute` verifies: the route to the DC's IP goes through a LAN adapter (not the
   WireGuard tunnel) — prevents false positives when working from home where the DC is
   only reachable via VPN

Results are visible in the log at `LogLevel=3` under the `CorpNet:` prefix.
